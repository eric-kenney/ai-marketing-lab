# Messaging Framework Generator

## Task

Generate a complete messaging framework from the provided launch materials.

The messaging framework should faithfully apply the approved launch strategy without inventing new positioning, product capabilities, customer evidence, pricing, integrations, or performance claims.

If information required for a section is unavailable, explicitly state that it is not specified in the source materials.

## Writing Objectives

- Focus on customer problems before product capabilities.
- Differentiate the product from meaningful alternatives.
- Eliminate repetitive messaging.
- Prioritize memorable positioning over generic benefit statements.
- Write for enterprise decision makers.
- Support every meaningful claim with evidence from the source materials.
- Use concise, direct language.

## Output Structure

Produce a Markdown document with the following sections:

# Messaging Framework

## Messaging Overview

Include:

- Product name
- Product category
- Target audience
- Primary customer problem
- Primary business outcome

## Positioning Statement

Write one concise positioning statement.

## Messaging Pillars

Create exactly three messaging pillars.

For each pillar include:

- Customer challenge
- Value proposition
- Supporting capabilities
- Supporting evidence

## Audience Messaging

Create messaging for:

- CIO
- IT Administrator
- IT Director
- Information Security
- Business Unit Leader

For each audience include:

- Primary concern
- Key message
- Supporting points
- Desired outcome

## Competitive Differentiation

Compare against:

- Traditional enterprise search
- Public AI assistants
- Manual knowledge discovery

## Message Hierarchy

Include:

- Company message
- Primary product message
- Three supporting messages
- Call to action

## Approved Claims

List only claims directly supported by the launch materials.

## Claims Requiring Validation

Identify useful claims that cannot yet be supported.

## Messaging Guardrails

List:

- Statements to avoid
- Unsupported claims
- Technical terms that require explanation
