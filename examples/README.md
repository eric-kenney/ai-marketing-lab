# Examples

This directory contains fictional examples demonstrating how AI Marketing Lab systems work with realistic product marketing inputs and outputs.

## Enterprise Product Launch

The `enterprise-product-launch` example demonstrates the AI GTM Launch Orchestrator using **Atlas Knowledge**, a fictional enterprise AI knowledge platform.

The example includes:

- A structured product brief, launch strategy, and launch plan
- An AI-generated messaging framework
- An AI-generated sales battlecard
- AI-generated product webpage copy
- Independent validation reviews for each generated asset

All products, companies, customers, claims, and launch materials in this example are fictional and were created specifically for this repository.
